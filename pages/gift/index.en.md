Access to the coworking room or the workshop is a gift that takes exactly as much time as the
person wants: a day, a week or a month. The certificate is bought in our store; the recipient
enters the code instead of paying when picking a plan.

## How it works

1. Buy the certificate in the [RainWalker store](https://store.rainwalker.ee/products/fab20-gift-card) — the code arrives
   by email.
2. Hand the code to the recipient.
3. The recipient signs in with SmartID, picks a plan and enters the code instead of paying. The
   door opens from the phone.

The certificate is not tied to a date — use it whenever convenient.
