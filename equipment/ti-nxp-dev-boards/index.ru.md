Контейнер для тех, кому надо попробовать не STM32.

Производители микроконтроллеров несовместимы между собой на уровне всего: периферии, среды
разработки, отладчика, способа настроить тактирование. Выбор вендора под проект — это решение на
годы вперёд, и принимать его по даташиту, ни разу не подержав плату в руках, довольно странно.
Поэтому платы разных вендоров лежат рядом.

## Что есть

- **TI LaunchPad с MSPM0L1117.** MSPM0 — недорогое семейство Texas Instruments на ядре Cortex-M0+,
  ориентированное на простые и дешёвые устройства. Среда — Code Composer Studio, отладчик на плате.
- **NXP FRDM-MCXN947.** Другой полюс: семейство MCX N с двумя ядрами Cortex-M33 и аппаратным
  ускорителем нейросетей на борту. Среда — MCUXpresso.

Обе платы пока лежат в заводских коробках, вместе с кабелями и бумажками.

## Чем это полезно

- Сравнить среды разработки до того, как выбрать вендора для своего проекта
- Попробовать то, чего нет у STM32: у NXP это NPU, у TI — ценовой уровень
- Повторить готовый пример от вендора, не покупая плату
- Понять, насколько больно переносить свой код с одной архитектуры на другую — обычно это
  выясняется слишком поздно

Если вы уже работаете с STM32, рядом стоит [контейнер с платами
STM32](/ru/oborudovanie/otladochnye-platy-stm32) и программаторами к ним.

## Набор будет расширяться

Пока это всё, что есть от TI и NXP: по одной плате. Набор задуман как растущий, и список выше
верен **на 19 октября 2026 года**.

**Если вам для проекта нужна конкретная отладочная плата, напишите нам.** Мы обычно готовы
докупить, и чаще всего она пригодится не только вам.

## Как пользоваться

1. Возьмите плату из контейнера вместе с её коробкой — в ней кабель и документация.
2. Поставьте среду разработки вендора: Code Composer Studio для TI, MCUXpresso для NXP. Обе
   бесплатные.
3. Отладчик у обеих плат на борту, отдельный программатор не нужен — хватит USB.
4. Верните плату в её коробку, а коробку в контейнер. Кабель туда же.

## Доступ

Контейнер стоит в помещении хакспейса, поэтому нужен тариф с доступом в хакспейс. Инструктаж не
требуется.
